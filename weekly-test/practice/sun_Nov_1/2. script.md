So, let me restate the problem. Given an integer x, I need to return true
if x is a palindrome — I mean, if it reads the same forward and backward.

Okay, so my approach is two pointers. I convert x to a string, then I put
one pointer at the start and one at the end, and move them toward each other.

Now, walking through the code. s = str(x), i = 0, j = len(s) - 1.
While i < j: if s[i] != s[j], return False. Then i += 1, j -= 1.
If the loop finishes, return True. Oh, and negative numbers fail naturally,
because the minus sign never matches a digit.

So, time complexity is O(n), space is O(n) for the string. Thank you.
