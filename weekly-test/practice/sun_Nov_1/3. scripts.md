So, the problem: given a list of strings, return their longest common prefix. If there is no common part, return an empty string.
My method is pairwise shrink. I start with the first string as my prefix. Then I compare it with each next word, pair by pair, and I keep only the part they have in common. So the prefix only shrinks or stays the same. It never grows. If it becomes empty, I return early.
Walking through the code. First, a guard for an empty list. Then prefix equals the first string. Then I loop through the rest. For each word, I move an index i forward while the characters match, then I cut the prefix down to its first i characters. If the prefix is empty, I return an empty string right away.
One example: flower, flow, flight. The prefix starts as flower, becomes flow, then f l. I return f l.
Time is O of n times m. Space is O of 1. Thank you.
