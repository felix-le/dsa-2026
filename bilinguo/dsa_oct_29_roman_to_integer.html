Pair 1 — Goal

Start here: what the problem gives, what it asks, and look through the examples first.

PROBLEM

Given a roman numeral, convert it to an integer.

Example 1:

Input: s = "III"
Output: 3
Explanation: III = 3.

Example 2:

Input: s = "LVIII"
Output: 58
Explanation: L = 50, V = 5, III = 3.

Example 3:

Input: s = "MCMXCIV"
Output: 1994
Explanation: M = 1000, CM = 900, XC = 90 and IV = 4.

THINKING

Given (input): a string s — a roman numeral string.

Asked (output): convert it to an integer.

Deduction: this problem is about reading each character in the string and computing a number — not search, not sort.

Pair 2 — Symbols

PROBLEM

Verify with "LVIII": 50 + 5 + 1 + 1 + 1 = 58 ✓ matches the answer.

Deduction: in the normal case, ADD up the value of each character from left to right.

Pair 3 — Subtraction Rule

The special-rule pair: where adding straight will be wrong.

PROBLEM

For example, 2 is written as II in Roman numeral, just two ones added together. 12 is written as XII, which is simply X + II. The number 27 is written as XXVII, which is XX + V + II.

Roman numerals are usually written largest to smallest from left to right. However, the numeral for four is not IIII. Instead, the number four is written as IV. Because the one is before the five we subtract it making four. The same principle applies to the number nine, which is written as IX. There are six instances where subtraction is used:

  • I can be placed before V (5) and X (10) to make 4 and 9.
  • X can be placed before L (50) and C (100) to make 40 and 90.
  • C can be placed before D (500) and M (1000) to make 400 and 900.

THINKING

Verify with "IV": adding straight 1 + 5 = 6, but the answer is 4 ✗ — adding straight is not always correct.

Observe: I (1) stands BEFORE V (5) — a smaller character before a larger character (smaller before larger) → must SUBTRACT: 5 − 1 = 4.

Deduction: at each position, compare the current character with the NEXT character: smaller → subtract; otherwise → add. The last character has no next → always add.

Pair 4 — Constraints

The final pair: the constraints tell you what you do NOT need to do.

PROBLEM

Constraints:

  • 1 <= s.length <= 15
  • s contains only the characters ('I', 'V', 'X', 'L', 'C', 'D', 'M').
  • It is guaranteed that s is a valid roman numeral in the range [1, 3999].

THINKING

The string is at most 15 characters long, and is always a valid roman numeral (guaranteed valid) → no input validation needed.

Deduction: a single pass from left to right is enough.

↑ Back to top

Thinking Summary

  1. Go from left to right, accumulating into a running total.
  2. At each character, look at it together with the NEXT character: smaller → SUBTRACT; otherwise → ADD.
  3. The last character has no next → always add.
