Full problem

Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

An input string is valid if:

  1. Open brackets must be closed by the same type of brackets.
  2. Open brackets must be closed in the correct order.
  3. Every close bracket has a corresponding open bracket of the same type.

Example 1:

Input: s = "()"

Output: true

Example 2:

Input: s = "()[]{}"

Output: true

Example 3:

Input: s = "(]"

Output: false

Example 4:

Input: s = "([])"

Output: true

Example 5:

Input: s = "([)]"

Output: false

Constraints:

- 1 <= s.length <= 104

- s consists of parentheses only '()[]{}'.

Pair 1 — Định nghĩa & ký hiệu

ĐỀ

Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

An input string is valid if:

  1. Open brackets must be closed by the same type of brackets.
  2. Open brackets must be closed in the correct order.
  3. Every close bracket has a corresponding open bracket of the same type.

PHÂN TÍCH

Đầu vào (input) là một chuỗi (string) s chỉ chứa các ký tự (character) là dấu ngoặc (bracket). Có 3 loại dấu ngoặc: ngoặc tròn (), ngoặc nhọn {}, ngoặc vuông []. Mỗi loại có một ngoặc mở (open bracket) và một ngoặc đóng (close bracket) đi với nhau.

Valid nghĩa là hợp lệ. Một chuỗi được gọi là hợp lệ khi thỏa cả 3 quy tắc sau:

  1. Quy tắc 1 — cùng loại (same type): ngoặc mở phải được đóng bằng ngoặc đóng cùng loại với nó. Ngoặc tròn mở thì phải đóng bằng ngoặc tròn đóng, ngoặc nhọn mở thì đóng bằng ngoặc nhọn đóng, ngoặc vuông mở thì đóng bằng ngoặc vuông đóng. Đóng bằng loại khác là không hợp lệ.
  2. Quy tắc 2 — đúng thứ tự (correct order): các ngoặc mở phải được đóng theo đúng thứ tự. Thứ tự đóng phải khớp với thứ tự mở. Đóng sai thứ tự thì chuỗi không hợp lệ, dù các loại ngoặc vẫn đúng.
  3. Quy tắc 3 — có ngoặc mở tương ứng (corresponding): mỗi ngoặc đóng đều phải có một ngoặc mở tương ứng (corresponding open bracket) cùng loại với nó. Một ngoặc đóng không có ngoặc mở tương ứng thì chuỗi không hợp lệ.

Cả 3 quy tắc đều phải đúng thì chuỗi mới hợp lệ. Chỉ cần một quy tắc sai là chuỗi không hợp lệ.

Từ khóa (keywords): string — chuỗi; character — ký tự; valid — hợp lệ; bracket — dấu ngoặc; open bracket — ngoặc mở; close bracket — ngoặc đóng; same type — cùng loại; correct order — đúng thứ tự; corresponding — tương ứng.

Pair 2 — Mục tiêu (task + examples)

ĐỀ

Determine if the input string is valid.

Example 1:

Input: s = "()"

Output: true

Example 2:

Input: s = "()[]{}"

Output: true

Example 3:

Input: s = "(]"

Output: false

Example 4:

Input: s = "([])"

Output: true

Example 5:

Input: s = "([)]"

Output: false

PHÂN TÍCH

Nhiệm vụ (task) của bài là: xác định (determine) xem chuỗi đầu vào có hợp lệ hay không. Đầu vào (input) là một chuỗi s. Đầu ra (output) chỉ có hai giá trị: true nếu chuỗi hợp lệ, false nếu chuỗi không hợp lệ. Bài chỉ hỏi đúng hay sai — không yêu cầu liệt kê, sửa hay đếm gì thêm.

Mỗi example kiểm tra một điểm ở mức quy tắc:

  • Example 1 — s = "()" → true: cặp ngoặc đơn giản nhất. Một loại ngoặc, một cặp, đóng đúng loại và đúng thứ tự.
  • Example 2 — s = "()[]{}" → true: nhiều loại ngoặc đặt cạnh nhau. Mỗi cặp đóng đúng loại và đúng thứ tự, nên cả chuỗi hợp lệ.
  • Example 3 — s = "(]" → false: vi phạm quy tắc 1. Ngoặc mở ( nhưng lại đóng bằng ] — sai loại.
  • Example 4 — s = "([])" → true: ngoặc lồng nhau (nested). Cặp [] nằm bên trong cặp (), mỗi cặp đóng đúng loại và đúng thứ tự, nên chuỗi hợp lệ.
  • Example 5 — s = "([)]" → false: vi phạm quy tắc 2. Các loại ngoặc đều có đủ, nhưng thứ tự đóng sai. Đúng loại chưa đủ — thứ tự cũng phải đúng.

Hai example false cho thấy hai kiểu sai khác nhau: sai loại (Example 3) và sai thứ tự (Example 5). Hai example true với nhiều cặp (Example 2) và lồng nhau (Example 4) cho thấy hợp lệ không chỉ là một cặp đơn.

Từ khóa (keywords): determine — xác định; input — đầu vào; output — đầu ra; true / false — đúng / sai; nested — lồng nhau.

Pair 3 — Constraints (ràng buộc)

ĐỀ

Constraints:

- 1 <= s.length <= 104

- s consists of parentheses only '()[]{}'.

PHÂN TÍCH

Constraint là ràng buộc — giới hạn mà đầu vào luôn thỏa. Có hai ràng buộc:

  • Độ dài (length): 1 <= s.length <= 104 nghĩa là chuỗi có ít nhất 1 ký tự và dài nhất 10.000 ký tự. Không có chuỗi rỗng, vì độ dài tối thiểu là 1. Chuỗi dài tối đa 10.000 ký tự — đọc một lượt qua chuỗi là đủ.
  • Chỉ chứa dấu ngoặc: s consists of parentheses only nghĩa là mọi ký tự trong chuỗi đều là một trong 6 dấu ngoặc ()[]{}. Không có chữ cái, chữ số, khoảng trắng hay ký tự nào khác.

Từ khóa (keywords): constraint — ràng buộc; length — độ dài; consists of … only — chỉ gồm …
