## SQL — from zero, a little every day

SQL from scratch, one small piece per day, with repetition so it sticks:

- One concept a day (SELECT → WHERE → ORDER BY → GROUP BY → JOINs → subqueries), then 1–2 LeetCode SQL 50 problems using it
- Every query written by hand before checking the answer
- End of week: re-do the week's queries from memory
- Goal: fluent interview-level SQL
